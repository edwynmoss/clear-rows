## What's new

**Checking for updates tells you the truth.** Being up to date and being unable to ask were reported the same way, so asking for updates while the release manifest was unreachable answered "Clear Rows is up to date". The app had not established that and could not know it. A check that cannot be made now says so, with the reason underneath. The automatic check still stays quiet whatever the answer, because being offline is ordinary.

This matters because the ways an update path breaks are silent ones: a missing manifest and a release signed with the wrong key both look exactly like already having the newest version.

## If you are on 1.1.1 or earlier

The repository was rebuilt on 7 September 2026 and the earlier releases went with it, so for a short window there was nothing for the app to find and every manual check answered "up to date". Nothing was wrong with your copy, and nothing was lost from it: Clear Rows reads your files locally and has never sent anything anywhere. This release restores the update path. Direct download links to installers from earlier releases no longer resolve, so take a fresh one from the releases page.

## Install

- **Windows setup (per-user, recommended):** `Clear Rows_1.1.2_x64-setup.exe`
- **Windows MSI (for IT-managed installs):** `Clear Rows_1.1.2_x64_en-US.msi`
- macOS universal `.dmg`, Linux `.AppImage`, `.deb` and `.rpm` are attached as well.

Installed copies of 1.0.1 or later will offer this update on launch.

The Windows and macOS builds are not code-signed, so expect SmartScreen ("More info, then Run anyway") or, on macOS, right-click then Open. Every release is still signed with the project's own key and the signature is checked before an update installs. Tested on Windows only.
