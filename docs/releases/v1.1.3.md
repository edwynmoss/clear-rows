## What's fixed

**Filtering now takes you to the first matching row.** If you scrolled down a large file before pressing Ctrl+F, the filtered table could stay at the old position and leave the results out of view. Applying or replacing a filter now starts at the top, including filters chosen through the builder or column tools. The query keeps keyboard focus, and matching results keep your horizontal scroll position.

Filters with no matches now clear the grid's loading state and show an empty table. Sorting and clearing a filter retain their existing scroll behavior.

Fixes [#2](https://github.com/edwynmoss/clear-rows/issues/2). Thanks to Podbrushkin for the report.

## Install

- **Windows setup (per-user):** `Clear Rows_1.1.3_x64-setup.exe`
- **Windows MSI:** `Clear Rows_1.1.3_x64_en-US.msi`
- The release workflow also builds macOS universal and Linux packages.

Installed copies of 1.0.1 or later will offer the update after this release is published.

The Windows and macOS builds are not code-signed. Updater artifacts are signed with the project's key and checked before installation. Runtime validation is on Windows only; macOS and Linux remain untested on real hardware.
