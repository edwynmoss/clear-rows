## What's new

**Updates are noticed while the app is open.** Clear Rows now checks for a new release a few seconds after launch, every six hours while it stays open, and when the window regains focus after an hour away. Before this, only the launch check ran, so a release published while the app was already running went unnoticed until you checked by hand.

**Real notes in the update toast.** The toast now shows the first line of the release notes. Earlier releases showed a placeholder because the notes were written after the build; notes now live in the repository and travel with the release.

## Install

- **Windows setup (per-user, recommended):** `Clear Rows_1.1.1_x64-setup.exe`
- **Windows MSI (for IT-managed installs):** `Clear Rows_1.1.1_x64_en-US.msi`
- macOS universal `.dmg`, Linux `.AppImage`, `.deb` and `.rpm` are attached as well.

Installed copies of 1.0.1 or later will offer this update on launch.
