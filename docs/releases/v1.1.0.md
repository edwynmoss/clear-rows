## What's new

This release is about the middle of the journey: understanding what is in a file and narrowing it down.

**Inspect column.** Choose it from a column menu or the command palette. The pane shows rows in view, empties, distinct values, and a type-aware range: smallest to largest and the sum for numbers, earliest to latest for dates, length for text. Below that, the most common values with counts and shares. Click a value to keep only those rows, the minus to exclude them. The pane recounts whenever the filter changes, and a switcher at the top moves to the next column.

**Typed columns.** Columns are typed from the first rows. Numbers with thousands separators, currency marks and decimal commas sort as numbers; dates in ISO, day/month/year and month-name layouts sort as dates; identifiers like WS-00017 stay text. Numbers right-align in the grid, and the type shows in the header tooltip and the column menu.

**Recent filters.** Filters you have applied to a file are remembered and offered in the builder while the box is empty. One click brings one back.

**Gzip.** `.csv.gz` files open directly, in the app and in search across files.

**Also**
- Tests run on every pull request.
- All dependency security alerts cleared.
- README rewritten around how a session goes: open, understand, narrow, act.

## Install

- **Windows setup (per-user, recommended):** `Clear Rows_1.1.0_x64-setup.exe`
- **Windows MSI (for IT-managed installs):** `Clear Rows_1.1.0_x64_en-US.msi`
- macOS universal `.dmg`, Linux `.AppImage`, `.deb` and `.rpm` are attached as well.

Installed copies of 1.0.1 or later will offer this update on launch.
