# Clear Rows v1.1.4

This release fixes a memory-safety bug in a library used by the Linux desktop app
([GHSA-wrw7-89jp-8q8g](https://github.com/advisories/GHSA-wrw7-89jp-8q8g)).

The library passed a read-only pointer to an operation that writes through it.
In optimized builds this could cause a crash. We've applied the upstream fix to
the compatible library version used by Clear Rows, and verified that the test
which crashed before the fix now passes.

Release builds now require this Linux regression check to pass. Windows and macOS
are included in this release for consistent versioning; the affected library is
part of the Linux dependency stack.

The filter scrolling fix from v1.1.3 is included.
