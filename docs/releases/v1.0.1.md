## What's new

**Updates from inside the app.** From this version on, Clear Rows checks for a newer release a few seconds after launch and offers it in a toast. One click downloads it and restarts the app. "Check for updates" is also in the command palette (Ctrl K). If you are on 1.0.0, install this version by hand once; every version after it updates itself.

**Filter builder can be closed.** The builder that opens under the filter box now has a close button. Closing it, or pressing Escape, keeps your cursor in the field and no longer clears the active filter.

**Dependencies.** Development tooling and the Tauri runtime were brought up to date, clearing every open security alert that applies to the shipped app.

## Install

- **Windows setup (per-user, recommended):** `Clear Rows_1.0.1_x64-setup.exe`
- **Windows MSI (for IT-managed installs):** `Clear Rows_1.0.1_x64_en-US.msi`
- macOS and Linux builds are attached below as well; these are the first builds for those platforms and have not been tested by hand yet.
